# NoseconeTipFTCS
A numerical (first-order) simulation of stagnation point heating for the nosecone tip.

- Based on the MIT Rocketry Team's (relatively basic, but definitely sound!) method for determining heating at the stagnation point: [Nose Cone Tip Thermal Analysis](https://wikis.mit.edu/confluence/display/RocketTeam/Nose+Cone+Tip+Thermal+Analysis).
- Also utilizing various resources for the FTCS iterative numerical method for heating.

## Usage

1. Put simulations from RASAero into the "sims" folder.
2. Replace the name of your desired nosecone tip material and bluntness.
3. Run the MAIN function.
